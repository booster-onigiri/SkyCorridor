# 空の回廊 — v0.1.2の遊び方

誰もいなくなった天空都市で、小さな端末を使い、かつての暮らしの痕跡を集める探索ゲームです。
無料のWindows試作版で、ゲーム内表示は日本語・英語に対応しています。

## 起動と保存

ZIP全体を書き込みできるフォルダーへ展開し、**Windows** フォルダーと同じ場所にある
**PLAY.cmd** を起動します。ZIP内から直接起動しないでください。Unreal Editorは不要です。
64bit Windows / DirectX 12用です。最低動作環境は未確定です。

初回にMicrosoft Visual C++ランタイムのインストール案内が表示された場合は、
内容を確認してインストールしてください。ランタイム不足で起動できず案内も出ない場合は、
同梱の **Windows\Engine\Extras\Redist\en-us\vc_redist.x64.exe** を実行し、
画面に従ってインストールしてから **PLAY.cmd** を起動し直してください。

保存先は **PLAY.cmdの隣のPlayData** です。更新前はゲームを終了し、PlayData全体を
バックアップしてください。更新版は別フォルダーへ展開してから移行し、進行状況を確認するまで
旧版を残してください。ブラウザーキャッシュにも追加の空き領域を使用します。

## 最初の記録

1. 時計広場の水辺から始めます。
2. **Q → 左上の目のアイコン「観測」→「観測を始める」** を選びます。
3. **Q / Esc** で端末をしまい、水辺の薄い人影へ近づいて少し眺めます。
4. 案内が出たら **E** で記録します。
5. **Q → 本のアイコン「記録」** で読み返し、**地図** から次の場所を選びます。

端末のホームは上段から、**観測・地図、記録・YouTube、友人・カメラ** です。
下端の短いバーでホームへ戻ります。

## 街を巡る

時計広場駅の水都線で白塔の水都へ移動できます。駅の昇降機から上層線へ上がると、
雲上ホテル、天空シアター、空中港を巡れます。図書館、美術館、カフェ、屋上にも入れます。
街の1日は現実の30分です。

大型モニターは近くの光る小型端末に近づき、**E** で操作します。
**Esc** で離れても上映は続きます。YouTubeにはインターネット接続が必要で、
広告・画質候補・再生可否は配信元に依存します。再生機能はパッケージ版用です。

## この版の範囲

一人での探索が中心です。「街を探す・街を開く」「みんなで映画を見る」「世界の卵・追加要素」と端末の「友人」は
**開発中**と表示され、選択できません。Tキーによる街の画面も開きません。
一人用の動画視聴・釣り・図鑑・撮影・客室訪問は利用できます。
別回線の多人数接続や実機の立体音響には未検証の条件があります。
メニュー、端末、痕跡の記録、地名、交通案内、釣りの説明を英語でも表示できます。開発用の実験機能やYouTubeの外部コンテンツは翻訳対象に含みません。

問題の報告には **v0.1.2**、Windows/GPU、場所、操作、昼夜を添えてください。

## 言語の切り替え

タイトル画面または「画質と操作」の **Language / 言語: 日本語 → English** で英語に切り替えられます。英語では **Language / 言語: English → 日本語** で戻せます。設定は `PlayData/language.txt` に保存され、既存の探索・記録データは維持されます。初回は日本語Windowsなら日本語、それ以外なら英語です。開発用には `-EWLanguage=en` / `-EWLanguage=ja` も使用できます。
